# 90-second portfolio demo walkthrough

Use this sequence to record a short screen capture or live walkthrough:

1. **Login and dashboard (0:00-0:15)** - Show the welcome screen, current metal rates and the dashboard totals.
2. **Inventory (0:15-0:30)** - Open stock, show barcode/product fields, purity, gross/net weight and rate history.
3. **Sales invoice (0:30-0:55)** - Create a demo sale, select a customer, add a gold or silver item, show GST and split payment totals.
4. **PDF output (0:55-1:10)** - Open the generated invoice and point out shop settings, customer details, HSN/HUID, weights, making, GST, QR and signature.
5. **Operations (1:10-1:25)** - Show cashbook, customer ledger, Excel export and printer configuration.
6. **WhatsApp boundary (1:25-1:30)** - Explain that only opted-in sales invoice PDFs are queued, and that credentials remain environment-only.

Use disposable demo credentials and seeded data. Do not record the shop database, customer history, Meta access token or any real production screen.
